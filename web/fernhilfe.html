Fernhilfe

Auf der Box, der du helfen willst: Einstellungen → Sender & Playlists → Fernhilfe → „Fernhilfe erlauben – Code zeigen“. Den Code hier eingeben oder einfügen.

Alles wird mit dem Code verschlüsselt, bevor es über den Briefkasten im Internet (ntfy.sh) geht. Ohne den Code kann niemand mitlesen. Die Fernhilfe endet von selbst, wenn eine Minute lang nichts passiert (frühestens nach 10 Minuten).
